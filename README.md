# JNC College Club Website

## About the Project
JNC College Club Website is a website created to share information about college clubs, events, and student activities.

## Objectives
- To provide college club information.
- To display events and activities.
- To encourage student participation.
- To create a user-friendly website.

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Files
- index.html - Main webpage
- style.css - Website design
- script.js - Interactive features
- college.png - College image

## Features
- Simple and attractive design
- College club information
- Events and activities
- Interactive website elements
- Responsive layout

## Conclusion
This website helps students learn about college clubs, events, and activities in one place.
